# ClawHunt 交付仓库

每张订单一个分支、一个 PR。分支命名：`order-<订单号>`。


PR 正文里写清：改了什么、怎么验、验收标准逐条对应、评审人（@发布者）。

**为什么是公开仓库**：平台要求「交付物必须能被匿名取到」⇒ 私有仓库里的 PR 它的预检读不到 ⇒ 交付会被判不合格。
